============================================================
怎么用
============================================================

1. 双击 "SR Voiceover Roulette.exe"
   · 会弹一个 UAC 窗口问"是否允许此应用对你的设备进行更改？"-> 点"是"
     （本程序需要管理员权限。游戏和语音软件常以管理员身份跑，
      权限比它们低时，读按键、抢设备、置顶窗口都可能被 Windows 挡下来）
   · 第一次运行时 Windows 可能还会拦一下，点"更多信息"->"仍要运行"
   · 头一次打开还会浮出一张"第一次用？"的小卡片，点「去看看」直接跳到
     常见问题那一节（以后不会再弹）
2. 右下角托盘出现一个圆环图标（颜色跟你设的应用主题色一致），
   程序就绪，不弹任何窗口

注意：如果想让它开机就自动起来、又不想每次登录都点一次 UAC，
目前这两种做法只能二选一 —— 勾了"开机自动启动"的话，登录时会弹一次提权确认。

【单击 Y】直接重播上一个音效，不用开轮盘
【长按 Y】约 0.25 秒，屏幕正中央弹出轮盘
         3. 移动鼠标（不用点、不用点中任何东西），圆点会跟着走
         4. 松开 Y —— 圆点指着的那个音效就会播出来
         5. 松开时圆点还在正中的话：有声音在响就立刻停掉它，
            没声音就什么也不做（中心会写着当前是哪种）
         6. 想让喊话马上闭嘴：长按 Y 弹轮盘，圆点别动，直接松开
         7. 反悔了：轮盘弹着的时候点一下鼠标左键或右键，轮盘立刻收起来，
            什么都不会播（松手也不会）。按住 Y 不放也不会再弹回来，
            要重新弹轮盘就松开再长按一次

"长按"的判定时长可以在配置窗口的「快捷键」页调（默认 220 毫秒）。
觉得单击老是误弹轮盘，把这个值调大一点；觉得按住半天才出轮盘，就调小。

想换音效：把音频文件丢进 sounds 目录，右键托盘图标 →
   "重新扫描 sounds 目录"。

托盘菜单里还能：打开 sounds 目录、退出。


============================================================
配置窗口（新）
============================================================

打开方式：托盘图标右键 ->「设置…」，或者直接双击托盘图标。

窗口左边是五个页签（音效库 / 快捷键 / 轮盘 / 麦克风 / 说明），右边是轮盘预览。

【音效库】

sounds 目录里的所有音效都会列在这儿。
· 从格子拖到轮盘的某一格 -> **替换**那一格（格子数不变）
· 从格子拖到轮盘中间圆 -> 加到最后一个
· 已经在轮盘上的，格子会显示绿色"已在轮盘"
· 把轮盘的格子拖回音效库 -> 从轮盘移除（文件还在，只是不上了）
· 拖回之后轮盘的格子数会立刻少一个

【按文件夹分组】（v0.8.0 新增）

音效一多就乱，现在会按 sounds 里面的子文件夹自动分组：

  sounds/
    冰冰冰.wav               -> 分组「根目录」
    哎哟.wav                 -> 分组「根目录」
    整活/
      无语.wav               -> 分组「整活」
      尖叫/
        啊.wav               -> 分组「整活/尖叫」

· 递归所有层级，建几层都行，不用手动建分类
· 每组的标题右边会写这一组有几个音效（"整活 3 个"）
· 分组顺序按文件夹名排，根目录永远在最上面
· 键名带路径，所以**不同文件夹里可以有同名文件**，
  以前两个 alpha.wav 会互相顶掉，现在各是各的
· 移动或改名文件夹后，右键托盘 →"重新扫描 sounds 目录"即可刷新

【时长】（v0.8.0 修复）

每个音效格子右边会显示它多长，比如「MP3 · 0.86 秒」。
.wav 直接读文件头，.mp3 / .ogg / .flac / .m4a 走系统解码器，
偶尔慢一两秒是正常的（读完就缓存，第二次秒开）。

注意：新放进 sounds 的文件**不会自动上轮盘**，要自己在上面拖过去。
你自己删掉、或者从轮盘上拖下来的音效，程序**不会自动补回来**——
这样你才能按自己的喜好删改音效库（想把整盘恢复成出厂状态，
删掉 sounds.json 再启动即可，它会按 sounds 目录里的文件重新排满）。

压缩包里已经排好一组示例音效（8 个格），不喜欢直接换掉就行。

【快捷键】

· 呼出轮盘：默认 Y，可以改
· 长按时长：按住多久才弹出
· 重复上一个 / 顺序播放：绑一个键，按下就直接发声，不用开轮盘
· 切换轮盘：按住弹出"轮盘选择器"，松手切到选中的那套（默认不绑定）
· 单个音效的直按键：在右下角音效卡片的「快捷键」里设
· 开机自动启动：勾上就写一条注册表 Run 项（HKCU，只写自己名字的那条，
  取消勾选立刻删掉）；仅打包成 exe 的版本可用
  注意：程序要管理员权限，所以开机自启时登录后会弹一次 UAC，得点"是"才起来

【轮盘】

· 直径、中空比例、不透明度、是否显示音效名
· 外圈厚度：内圈满 8 个之后，外面那圈的厚度（内圈大小不受影响）
· 配色（v0.8.0 重做）：
  · 「应用主题色」= 整个设置窗口的配色，跟轮盘颜色是分开的两件事
  · 「本套轮盘颜色」= 只影响这个轮盘画出来的样子
  · 两边都能「选取…」自己调色，不再是只有绿橙蓝紫四个死选项
  · 勾「跟随主题色」就一直是应用那个色；不勾就单独设
  · 下面四个小圆点是快捷预设，懒得调就直接点
· 手感：鼠标灵敏度、中心死区、手抖过滤

【轮盘库】（v0.8.0 新增）

一个程序里存多套轮盘，最多 8 套，随时切换：

· 列表里一行一套，左边小圆点是这套的颜色，打勾的是当前这套
· 「切换到这套」：立刻换过去（轮盘页的预览也会跟着变）
· 「另存为新轮盘」：把当前配置复制一份出来，新起个名字
  （默认拷一份现在的样子，省得从零摆格子）
· 「重命名」「清空」「删除」：删除只删这一套，最后一套删不掉
· 每套各自记着自己的：格子布局、每个格子的音量/变调/速度/热键、
  以及这套自己的颜色 —— 换过去就是完整的一套，不用重新调

除了点按钮，还有两种切换方式：
1. 托盘图标右键 ->「轮盘」子菜单里直接选
2. 按住"切换轮盘"热键，屏幕中间弹出选择器，鼠标指向哪套松手就是哪套

切换器长什么样：一圈扇区，每格写一套轮盘的名字，
正中间显示"你现在指着的是哪套"。
鼠标指到某一格，那一整块就会亮成**这套轮盘自己的颜色**（没单独设过颜色的
才用应用主题色），中间的名字、鼠标的小圆点也跟着变色，一眼就知道要切去哪套。
松手瞬间完成切换，正在响的音效不会断。

【右下角的音效卡片】

点轮盘上任意一个扇区，下面那张卡片就会显示它的参数：

· 音量：单独调，100% 是原始音量
· 变调：不改变 / 连续播放时升调 / 降调 / 每次随机变调 / 固定变调
· ±N 半音：升调降调时是"每次变多少"，随机时是"随机范围"
· 固定变调：直接填 -24 ~ +24 半音，每次播放都变这么多（正升负降）
· 速度：不改变 / 连续播放时加快 / 变慢，每次快慢多少
· 连击窗口：多少毫秒内重复播放才算"连续"（变调和速度共用）
· 快捷键：单独绑一个键

变调规则举例：设成"升调、每次 ±2 半音、窗口 2500ms"，
你在 2.5 秒内连按 3 次，就是原调、+2、+4 依次变尖。
停手超过 2.5 秒，下次又是从原调开始。

随机变调举例：设成"每次随机变调、±3 半音"，
每按一次就从 -3、-2、-1、0、+1、+2、+3 里抽一个半音来放，
而且不会连着两次抽到同一个（连按起来每次都跑不同的调）。
随机模式不看连击窗口，随时按随时抽。

固定变调举例：设成"固定变调、-5 半音"，
不管按多少次、隔多久按，每次都是同一个降了 5 半音的声音。
适合"这个音效我永远想要低沉版/尖锐版"这种需求。

速度规则举例：设成"加快、每次 10%、窗口 2500ms"，
2.5 秒内连按 4 次，就是原速、+10%、+20%、+30%（最多到 +60%）。
和变调不一样：**音调不变**，只是说话的语速变了，不会变尖也不会变沉。

速度和变调可以同时开：比如"升调 + 每次 2 半音"配上"加快 + 每次 10%"，
连按起来就是又高又快，两条规则各算各的。


============================================================
组合音效（v0.7.1 新增，v0.7.2 大扩充）
============================================================

可以把几个音效编成一个"◆ 组合"，像普通音效一样拖上轮盘、绑直按键、
调整体音量。入口在配置窗口「音效库」页最底下的「组合音效」。

【怎么建】
点「＋ 新建组合」→ 左边双击音效加入（同一音效可重复加）→
每一行就是一个成员，行序 = 播放顺序，用"上移/下移"调。

【每个成员可以设什么】
· 音效：这一列是下拉框，随时能换；文件被删或改了名的会标「⚠ 缺失」
· 触发条件：组合开始时 / 上一项开始后 / 上一项结束后
· 延迟：相对触发点等多少毫秒，可以填 -5000 ~ 10000
  填负数 = 提前起，能让后一项叠到前一项的尾巴上，衔接更顺不突兀
· 音量 / 变调 / 速度：和普通音效一样，都只管这一项
· 起点 / 长度（选中一行后在下面那条里调）= 片段裁剪
  起点：从原音效的第几毫秒开始取；长度：只取多长，0 = 一直到结尾
  想"只要起手那一下""只要收尾那一声"就靠这两个
· 随机变调± / 随机变速±：每次触发在这一项上抖一下，别每遍都一模一样

【组合整体参数】
· 速度 / 变调：乘（加）在每项自己的参数上，改一处等于全组合一起改
· 随机速度± / 随机变调±：每次触发整体抖一下，全组合共用同一个值
  效果是"这一遍整体偏高 / 偏快一点"，而不是每项各跑各的调
· 冷却：触发后多少毫秒内再按无效，防止连点把同一条叠成一团糊音
· 最多同时：同一条组合最多几条声音一起响，超了先掐最早那条，0 = 不限
  长组合连按时这个特别有用
· 专属热键：给这条组合单绑一个键，不必占轮盘格子也能按

【播放方式】
· 按顺序全部播放：从第一项到最后一项，每项按自己的触发条件响
· 随机抽取 N 个播放：每次随机抽 N 项（不重复）接龙；
  勾"抽到后打乱顺序"可以连顺序也随机
· 按顺序点击播放：每按一次只响 1 项，按顺序往下走，播完最后一项
  回到第一项，一直 ABCDABCD 循环。适合"一下一下往外蹦"的玩法。
  注意：一次只有一项在响，它就是起点，所以只有触发条件设成
  「组合开始时」的那一项，它自己的延迟才会生效
· 累加播放：第 1 次响第 1 项，第 2 次响前 2 项，第 3 次响前 3 项……
  叠满全部之后回到第 1 项重新累加，一直循环。越点越乱，建议配冷却用

【表格下面那条时间条】
只读的：每项一根条，起点 = 什么时候响，长度 = 响多久，
互相压住的会自动分成几行，一眼能看出谁盖着谁、中间哪段是空的。
它不能拖也不能改 —— 这不是 v0.7 那个会错位、会卡死的可编辑音轨，
只是一张"地图"。

【递进复制】
选中一行 →「递进复制…」→ 填"复制几份 / 每份变调 +几半音 /
每份变速 +几% / 每份延迟 +几毫秒"→ 一次生成一串逐级变化的成员，
不用手填三遍数字，也不会算错先后。
例："三连升调" = 选中第一项 → 2 份 / +2 半音 / +0% / +200ms。

【改错了怎么办】
· 撤销：Ctrl+Z，或左下角「撤销」按钮（最多退 80 步）
· 重做：Ctrl+Y（Ctrl+Shift+Z 也认）
· 「从这行开始试听」：跳过前面的成员，只从选中那行往后播，
  调长组合时不用每次都从头听

【导出 WAV】
「导出 WAV」把这条组合按当前设置渲染成一个音频文件（16bit 双声道），
可以直接丢进剪辑软件。导出的东西和听到的一致（随机抖动不参与，
这样导出的文件每次都是同一版，可复现）。

【两个现成的配方】
① "A 原版 → 0.2 秒后 A(升调+加速) → 0.2 秒后 A(降调+减速) → A 播完紧接 B"：
   四项依次设：组合开始时 0ms / 上一项开始后 200ms / 上一项开始后 200ms /
   上一项结束后 0ms，每项各调各的变调速度。
   更快的方法：建好第一项 →「递进复制」2 份、每份 +2 半音、延迟 +200ms，
   再把最后一项换成 B。
② "ABCD 里每次随机抽 3 个、间隔 1 秒"：
   播放方式选"随机抽取 N 个"、N=3；成员的触发条件全部设
   "上一项开始后 1000ms"（第一项保持"组合开始时"）。

【几条规则】
· 排程在按下那一刻一次算完，不用定时器，越按越飘/卡顿不复存在
· 成员文件被删了：那一项自动静音，表格里标「⚠ 缺失」和「缺失」，
  下拉框直接挑个别的顶上就行，其他项照常响
· 一个组合最多 24 项；组合存在 sounds.json，不占 sounds 目录
· "试听这一项"只放选中那项；"试听整个组合"按当前设置完整走一遍
· 启动后会把所有组合预渲染进缓存，第一次按也不会有解码延迟


============================================================
麦克风注入（v0.6.0 新增）
============================================================

作用：让游戏/语音软件里的队友也听到你的音效，而不只是你自己能听见。


【前提】必须装一个虚拟声卡，免费的 VB-CABLE 就够：
   https://vb-audio.com/Cable/
   装完**必须重启电脑**，设备才会出现。
   这是 Windows 的限制：普通程序没办法直接往别人的麦克风里塞声音，
   必须有一个"假的录音设备"当中间站。没有别的办法。


【三步设置】

1. 打开配置窗口 ->「麦克风」页
2. 「采集麦克风」选你平时说话的那个（比如"耳机式麦克风"）
   「虚拟声卡」选 CABLE Input
3. 勾上「把音效送进游戏语音」
   点「开始测试」说一句话，绿条跟着动就说明麦克风采到了

然后进游戏/语音软件的设置，把「麦克风」改成 **CABLE Output**：
   · MC 的 Simple Voice Chat：它自己的设置里换，改完要重启游戏
   · KOOK / Discord：设置里的"语音输入设备"，改完立刻生效


⚠ 一个容易踩的坑：
   装完 VB-CABLE，Windows 的默认录音设备会被改成 CABLE Output。
   如果这时候没开本程序的注入、又用着"默认设备"，
   队友会完全听不到你说话（听起来像你麦克风坏了）。
   解决办法二选一：勾上注入开关，或者把系统默认录音设备改回你的真麦克风。
   程序在「麦克风」页也会直接把这句警告显示出来。


⚠ 另一个更容易慌的坑：装完 VB-CABLE，整个电脑都没声音了
   它还可能把 Windows 的**默认播放设备**改成 CABLE Input。
   这等于把全电脑的声音（歌、视频、游戏）全灌进假声卡肚子里，
   而那个假声卡没人"听"，所以喇叭和耳机一点动静都没有。
   解决：点右下角小喇叭 -> 上面那行设备名点一下 -> 选回你的耳机/音箱
   （别选带 CABLE 字样的那个）。改完放首歌确认一下。
   不用担心跟本程序打架：本程序是自己在「虚拟声卡」那一栏里单独找 CABLE Input 的，
   跟系统默认播放设备是两回事，默认设备还给耳机，音效照样送得进游戏。
   （详见程序内「说明」页 ->「四、常见问题」Q5）


【麦克风认不出来怎么办】

程序对麦克风是"能用就行"，不挑格式：
   · 蓝牙耳麦常见的 16kHz / 单声道、部分 USB 麦克风只给 44.1kHz，
     都会自动转成内部要用的 48kHz 立体声，音质按设备本身走，不会没有声音
   · **同一台麦克风会把所有能试的格式试穿**（48k 立体声 -> 48k 整型 ->
     单声道 -> 44.1k -> 16k），才轮到换下一台设备。
     有些设备嘴上说"48kHz 立体声没问题"、真去打开却拒绝（虚拟声卡、蓝牙、
     被别人共享着的设备都这样），以前这种会直接判死，现在会自动退到能用的那一档，
     状态栏里会写「已自动适配到 16kHz 单声道」这类说明
   · 选中的麦克风打不开（被别的软件占着），会自动换系统默认的那一个，
     再不行就把其余麦克风挨个试一遍
   · 用到中途拔掉再插回来，程序几秒内会自己接上，不用重启
   · 麦克风确实起不来时，托盘会弹一条提示，不会"以为在送声、其实没有"
   · 如果下拉框里只找出虚拟声卡（CABLE Output 这类），会照样列出来并写明
     「虚拟设备，选它对方听不到你说话」，不再干巴巴显示"没检测到麦克风"

真的起不来，按这个顺序查：
   1. Windows 设置 -> 隐私和安全性 -> 麦克风，确认"允许桌面应用访问"是开的
   2. 关掉可能独占麦克风的软件（某些语音软件、直播工具会锁住设备）
   3. 「麦克风」页点「重新检测设备」再选一次
   4. 还是不行就看程序目录下的 sr_roulette.log，里面写着试过哪些设备、
      每个是因为什么失败的（新版的错误信息会带「试了几种格式」和具体格式）

⚠ 如果你用的是 v0.7.6 或更早的版本，看到「xxx 不支持 48kHz 立体声」这句话，
   那不是你麦克风的问题，是旧版只认这一种格式。换新版即可。


【三个音量】

· 音效·送对方  —— 队友听到的音效多响
· 原声·送对方  —— 队友听到的"你说话"多响
· 本地监听    —— 你自己耳机里的音效多响（也可以整个关掉，只听队友那边）


【请戴耳机】

外放音箱的话，喇叭里出来的音效会被麦克风再录一遍送出去，
队友会听到"你说话 + 带回声的音效"叠在一起，很乱。
这个只能靠戴耳机解决，程序管不了。


【延迟】

你说话到队友听到，大约 120 毫秒，日常聊天够用。
「缓冲余量」拉大更抗卡顿、拉小更跟手；
如果出现持续的咔哒声，先把余量往上加一档。


【说明】

· 默认是关的。不勾这个开关
· 「音效·送对方」和「本地监听」是两套独立音量
· 音效和你的原声是分两路混的，调音效音量不会连带改变你说话的音量


============================================================
重要：先去游戏里把 Y 键解绑，或者换轮盘触发键为你想要的按键
============================================================

本程序设计上只"旁听"按键，不拦截、不屏蔽。
你按 Y 的时候，游戏自己也会收到这个 Y。

所以务必进游戏设置，把 Y 键原来的功能改到别的键上，
否则每次开轮盘，游戏那边也会跟着执行一次 Y 的操作。


============================================================
可以调的参数（config.json）
============================================================

用记事本打开 config.json，改完保存，重启程序生效。

  hotkey            热键，默认 "y"。也可写 f8、space、comma 等
  hold_ms           长按多少毫秒才弹出轮盘，默认 180
  volume            音量，0.0 ~ 1.0，默认 0.8
  slots             最多加载几个音效，默认 8
  open_settings_on_start  启动时自动打开配置窗口，默认 true
  autostart         开机自启动（写当前用户注册表 Run 项），默认 false。
                    建议直接在「快捷键」页的「启动」卡片里开关，效果一样

  sensitivity       鼠标灵敏度倍率，默认 0.85
                    觉得圆点跑太快就调小（如 0.5）
                    觉得推半天推不满就调大（如 1.4）
  deadzone_px       中心死区，默认 24。小于这个距离不算选中
  noise_floor       手抖过滤，默认 2。静止时鼠标报出的极小位移
                    会被丢弃，防止圆点自己漂走
  max_offset_ratio  圆点最远能推到半径的多少，默认 0.9

  wheel_radius      轮盘半径像素，默认 180
  wheel_anchor      轮盘弹在哪，默认 "screen"（屏幕正中）
                    改成 "cursor" 就是跟随鼠标
  inner_ratio       中心圆占半径的比例，默认 0.42
  opacity           扇区不透明度，默认 0.94
  show_names        是否显示音效文件名，默认 true

  fade_ms           淡入淡出时长，默认 6 毫秒。改成 0 会有咔哒声
  audio_buffer_ms   音频缓冲，默认 60 毫秒。调小更跟手，但太小会卡顿

                    的 "SR Voiceover Roulette" 一条，界面里勾选更省事

如果调坏了，直接删掉 config.json，程序会用默认值重新生成。


============================================================
音效文件
============================================================

支持 .wav / .mp3 / .ogg / .flac / .m4a
按文件名排序分配槽位，所以建议命名成
  01_xxx.mp3
  02_xxx.mp3
  03_xxx.mp3
这样顺序才可控（按字母序，不是数字序，01 02 03 这种写法最稳）。
轮盘会按文件数量自动均分扇区，现在 5 个就是每个 72°。
以后加音效继续往下编号就行（06、07...），不用改任何设置。

想分类就建子文件夹（v0.8.0）：
  sounds/整活/、sounds/整活/尖叫/ 都行，几层都认，
  音效库里会按文件夹分好组显示，不同文件夹里可以有同名文件。
排序是"文件夹名优先，再按文件名"——根目录的排最前面。

删音效直接删文件，或者再往里加。右键托盘 →"重新扫描 sounds 目录"
就会重新分配槽位（文件夹结构改了也要点这个）。


============================================================
已知限制
============================================================

* 轮盘打开期间如果手在鼠标上晃动，圆点会跟着晃。这是"跟着手感走"
  的必然结果，不是 bug。长按 Y 的时候手放稳就行。

* 圆点不会自动回中。想换到反方向，把鼠标往回带即可。

* 把音效送进游戏语音，必须先装虚拟声卡（VB-CABLE 之类）。Windows 没有
  让普通程序直接"插进别人麦克风"的接口，这一步绕不开。

* 送进语音的音效会比本地慢一点点（约 120 毫秒）。这是虚拟声卡 + 缓冲
  的固有代价，唱歌打拍子可能感觉得到，日常喊话听不出。

* 外放音箱时音效会被麦克风二次收录，对方会听到回音。请戴耳机。


============================================================
排查
============================================================

出问题时先看同目录下的 sr_roulette.log，里面有启动和解码的记录。

常见情况：
* 托盘没有图标   → 可能已经开了一个，看右下角有没有那个圆环图标
* 长按热键没反应 → ① 设置窗口是不是在最前面？它是当前窗口时热键不响应
                    （免得在里面打字把轮盘弹出来），点一下游戏窗口就好；
                    设置窗口留在后台开着不影响。
                    ② 当前这套轮盘是不是空的（一个音效都没上盘），
                    日志里会写"当前这套轮盘是空的"。
                    ③ 热键被游戏占用了，换个 F9 之类的试试。
                    ④ 游戏以管理员身份运行，本程序也要是管理员
                    （双击时 UAC 弹窗要点"是"）
* 列表里音效数 0 → sounds 目录空，或格式不支持
* 轮盘能弹但选不了 → 看日志有没有 RegisterRawInputDevices 失败
* 轮盘不在屏幕中间 → 检查 config.json 的 wheel_anchor 是不是被改成 cursor 了
* 没有声音       → 检查系统默认输出设备，或把 volume 调大
* 切换轮盘热键没反应 → 先去「快捷键」页看有没有绑上（默认是空的，
  得自己绑一个键）；绑了还不行，看是不是跟游戏里同一个键冲突
* 时长显示"—"    → 该文件解码器读不出来（比如文件损坏、或者
  系统没装对应的解码器），不影响播放，只是算不出长度
* 音效库里分组不对 → 菜单 →"重新扫描 sounds 目录"刷新一次
